# Python Contact Book

A simple command-line contact management application built with Python. The program allows users to save, search, view, edit, and delete contacts. Contact information is stored in a JSON file so that the data can be saved and accessed again when the program is run.

## Features

- Save new contacts
- Search for contacts
- Display saved contacts
- Edit existing contacts
- Delete contacts
- Store contact information in a JSON file
- Automatically loads existing contacts when the program starts

## Concepts Practiced

- Python dictionaries
- Functions and program structure
- Loops
- Conditional statements
- User input
- String methods
- JSON
- File handling
- Exception handling
- Reading and writing files

## How to Run

Make sure Python is installed on your computer.

Run the program using:

python contactbook.py

Then choose an option from the menu:

1. Save Contact
2. Search Contact
3. Show Contact
4. Edit Contact
5. Delete Contact

## Data Storage

The application uses a `contacts.json` file to store contact information.

Example:

{
    "john": "0123",
    "alex": "0198"
}
